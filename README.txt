هاني سوفت — ملفات الموقع
========================

الملفات:
- index.html: الموقع كامل في ملف واحد (HTML + CSS + JavaScript).

التشغيل:
1. فك ضغط الملف ZIP.
2. افتح index.html في المتصفح لمعاينة الموقع.

النشر على GitHub Pages:
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع ملف index.html إلى جذر المستودع، وليس داخل مجلد فرعي.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، ثم Save.
5. انتظر اكتمال النشر وافتح الرابط الذي يعرضه GitHub Pages.

ملاحظات:
- الموقع ثابت ولا يحتوي على لوحة إدارة أو قاعدة بيانات.
- نماذج الطلب تفتح واتساب برسالة جاهزة؛ يجب على العميل الضغط على إرسال داخل واتساب.
- رقم واتساب مضبوط في الموقع على 84562812172 (من دون علامة + في رابط wa.me).
- الأسعار لا تُعرض في الموقع؛ يتم الاتفاق عليها عبر واتساب.
- خدمة iCloud موصوفة على أنها مساعدة بالطرق الرسمية واسترداد الحساب وإثبات الملكية.
